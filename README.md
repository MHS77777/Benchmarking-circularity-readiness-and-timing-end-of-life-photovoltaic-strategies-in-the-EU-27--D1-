# Will Europe's circular economy be ready for its solar waste wave?

**Benchmarking circularity readiness and timing end-of-life photovoltaic strategies in the EU-27 with dynamic fuzzy soft sets**

Code, frozen data, results and documentation for the manuscript by M. H. Saeed, M. Saeed, M. S. Habib, M. Ullah and Z. A. Khan, submitted to *Renewable and Sustainable Energy Reviews* (special issue *Embedding Circular Practices into Renewable and Sustainable Energy Production and Management*), October 2026.

Everything in the paper — every number, table, figure and workbook — is regenerated by one command from the public data frozen in `data/raw/`. No network access or credentials are needed.

```bash
pip install -r requirements.txt
./reproduce.sh          # ~1 minute on a laptop; also run by the GitHub Actions workflow
```

## What the paper does

| Layer | Question | Method | Headline result |
|---|---|---|---|
| **A** | How circular is each member state, when the yardstick itself changed in 2023? | Dynamic fuzzy soft set (DFSS) over the Eurostat circular-economy monitoring framework, 2012–2023, with time-varying active criteria sets | 65 % of the apparent 2020→2023 change in national scores is due to the framework revision, not performance; back-imputation and listwise restriction fail in opposite directions |
| **B** | When does each member state's PV end-of-life wave arrive, and how large is it? | IRENA/IEA-PVPS Weibull loss scenarios; mixture weight calibrated on nine years of Eurostat PV-panel WEEE collection data; Monte Carlo bands | 7.2 Mt by 2040, 20.9 Mt by 2050; national onsets 2029–2038 |
| **Coupling** | Where is readiness lowest relative to urgency? | Readiness gap G = urgency × (1 − readiness); rank probabilities from joint Monte Carlo draws | Greece, Bulgaria, Cyprus first to third in every draw; Germany and Malta share fourth |
| **C** | Which circular strategy should each archetype activate, and when? | DFSS over seven strategies × nine criteria × three horizons; institutional criteria from public governance and waste statistics | Reuse/refurbishment leads to 2040, high-value recycling after, in every archetype; export never dominant |

Start with [`ANALYSIS.md`](ANALYSIS.md) for the methods and numbers of each layer and the revision log (§8–§10), then `docs/` for the session-by-session build and audit record.

## Pipeline

| Script | Produces |
|---|---|
| `eurostat.py` | JSON-stat client with on-disk cache (`data/raw/`) |
| `build_panel.py` | indicator panel, 3-year windows, availability table, active parameter sets S1/S2 |
| `fetch_layer_b_data.py` | PV capacity, population, PV-panel WEEE collected / put on market |
| `layer_a.py` | DFSS scores and ranks, four baselines, activation decomposition (with a consistency assertion against the DFSS scores), clustering, 36-specification sensitivity |
| `layer_b.py` | cohort masses, Weibull mixture, calibration of π, mass check, Monte Carlo (EU-level band and per-draw gap ranks), wave timing, readiness gap and archetypes |
| `layer_c_proxies.py` | institutional capacities from WEEE and governance statistics; requirement matrix; fuzzy feasibilities |
| `layer_c.py` | strategy decision matrices per archetype and horizon, DFSS local/global scores, fuzzy TOPSIS baseline, perturbation sensitivity |
| `synthesis.py` | cross-layer synthesis table |
| `figures_a.py`, `figures_b.py`, `figures_c.py` | all figures |
| `make_tables.py` | all LaTeX tables (`manuscript/tables/`) |
| `build_workbooks.py` | the three Excel workbooks |
| `ingest_forms.py`, `questionnaire.js` | optional expert-validation track (Delphi responses → Layer C) |

## Data sources

- Eurostat: circular-economy monitoring framework (`cei_*`), net PV capacity (`nrg_inf_epcrw`), population (`tps00001`), WEEE statistics (`env_waselee`, Annex I scope 2016–2018; `env_waseleeos`, open scope 2019–2024).
- World Bank Worldwide Governance Indicators (`GOV_WGI_RQ.EST`, `GOV_WGI_RL.EST`, 2021–2023).
- IRENA/IEA-PVPS (2016): Weibull shape parameters, mass-per-watt factors, module composition.
- Literature anchors for the quantified strategy criteria: listed in `ANALYSIS.md` §5 and the supplement §S2.4.

Delete `data/raw/` to refresh from the live APIs; the clients fall back to the network automatically.
