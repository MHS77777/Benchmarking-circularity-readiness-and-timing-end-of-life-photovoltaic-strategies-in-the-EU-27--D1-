# Session 6 report — Track A: institutional criteria from public data

## What was done
1. **Discovery and correction.** Eurostat's open-scope WEEE dataset (env_waseleeos) reports photovoltaic panels as a separate line (EE_LE_PVP) for 2019–2024, 17–23 member states. The manuscript's statement that PV-specific statistics ended in 2018 was wrong and is corrected. The calibration of the loss mixture now uses 128 country-years (2016–2024), 71 in the fit: π = 0.18 (pooled); Germany 0.05, Czechia 0.03, Belgium 0.10, Spain 0.00, Italy 0.11, Netherlands 0.14, Portugal 0.16, France 0.28, Poland 0.89. Italy's 2022–2023 collection (21.9 / 30.0 kt) runs at the early-loss envelope — the Conto Energia revamping effect — and is discussed as the feedstock for cascaded second use. The same dataset reports PV modules put on market in tonnes: median ratio to capacity additions × vintage mass factor = 0.97 (IQR 0.72–1.30, 107 country-years), an independent validation of the mass assumption.
2. **Layer B numbers (central, continued deployment).** 1.4 / 7.3 / 20.9 Mt by 2030/2040/2050; onset 2029 (CZ) to 2038 (IE, LV); Germany 6.7 Mt (p10–p90 5.5–8.0). Priority group unchanged: EL 0.68, BG 0.49, CY 0.42, DE 0.38. Archetype membership unchanged.
3. **Layer C institutional criteria from proxies** (new module `layer_c_proxies.py`): C1 = WEEE collection rate + WGI regulatory quality; C2 = WGI rule of law + PV capture ratio; C3 = CE employment + CE investment + WEEE recycling/reuse rate; C4 = household WEEE collection kg/cap + municipal recycling rate. Country capacities → archetype capacities κ (L 0.55–0.72; CE 0.41–0.54; CL 0.50–0.57) → feasibility f = 1 − ρ(1 − κ) through a documented requirement matrix ρ(a,c) (Table 11, Supplement S3.1); within-archetype spread gives the fuzzy support. Treatment-location share was tested and dropped (uninformative: ≈ 100 % treated within the EU everywhere except Ireland).
4. **Layer C results.** Reuse first in H1/H2 everywhere; high-value recycling second in H2 and first in H3 everywhere; cascaded second use 2nd–3rd; export 3rd–4th in H1 only, 5th–6th after; take-back 4th–6th, rising; disposal last with non-overlapping supports. Top-1 reproduced in 97 % of cells under ±20 % perturbation of all criteria; TOPSIS τ = 0.96; middle ranks sensitive (τ mean 0.77, min 0.68) — stated as such.
5. **Manuscript.** Abstract, highlights, introduction, Sections 3.5–3.6, 4.2–4.4, Discussion, Limitations, Conclusion updated; Table 11 added; Delphi moved to Supplement S3 as a validation protocol; all "provisional" markers removed. 28 pages, ~9,000 words, 84 references. Three \rev{} items remain (e-mail, database search, AI declaration).
